## Approved Public Wording

### Data / Retention
Lumen is designed to minimize data retention and avoid raw-text storage. In supported deployments, message content is processed only for the immediate detection session and is not retained as a central raw-text database.

### Source Availability
Lumen ISSP is being prepared for a public source-available release under a defined release channel. Sensitive detection internals, adversarial fixtures, raw real-world cases, and raw governance records may be withheld or redacted to prevent misuse.

### FP=0
Lumen maintains a false-positive-zero red-line discipline on its current tested pattern set.

### Telegram Access Node
A beta Telegram access node is live for controlled testing. It is an access node for structural pattern analysis, not a production-grade judgment system or surveillance service.

## What Lumen Is Not

- Not an angel — it does not only flag bad actors
- Not a judge — it does not issue verdicts
- Not a surveillance tool — no central raw-text database
- Not a production guarantee — beta access node, controlled testing only
